# Nutri-Prévention : télécharger l'application

Logiciel de cabinet de nutrition. Il fonctionne entièrement sur
l'ordinateur, sans connexion internet : aucune donnée ne part ailleurs.

## Télécharger

Page **[Releases](../../releases/latest)** → section *Assets* :

| Ordinateur | Fichier |
|---|---|
| Mac (tous modèles) | `Nutri-Prevention-macos-intel.zip` |
| Windows | `Nutri-Prevention-windows.zip` |

## Installer sur Mac

1. Ouvrez le fichier `.zip` téléchargé : une icône **Nutri-Prévention**
   apparaît.
2. Faites-la glisser dans le dossier **Applications**.
3. Au premier lancement, le Mac affiche un avertissement : l'application
   n'est pas encore enregistrée chez Apple. **Clic droit** sur l'icône →
   **Ouvrir** → **Ouvrir**.
   Sur les versions récentes de macOS, si « Ouvrir » n'apparaît pas :
   **Réglages Système** → **Confidentialité et sécurité** →
   **Ouvrir quand même**.

Les fois suivantes, un double-clic suffit.
